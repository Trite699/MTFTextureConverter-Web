Universal MT Framework TEX ↔ PNG Studio

Fully aligned with Kuriimu2's plugin_mt_framework. Convert Capcom MT Framework texture files across all major engine revisions (PC, PS3, PS4, Xbox 360, Switch, 3DS, Vita, Android, iOS) into real viewable PNGs, or encode standard PNGs back into any game's native `.tex` header format.

Load binary .tex textures

Includes native in-browser shaders for RGBA8888, BGRA8888, RGB888, RGB565, RGBA5551, RGBA4444, L8, A8, LA88, ETC1, DXT1/BC1, DXT3/BC2, and DXT5/BC3. Unsupported console compression blocks (BC4/BC5/BC7/PVRTC/ATC) are extracted as clean raw binary blobs for specialized external processing.
