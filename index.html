MT Framework TEX → PNG Converter

Converts Capcom MT Framework Mobile .tex textures (the format used by the Android/iOS ports of Ace Attorney, Monster Hunter, and other MT Framework Mobile titles) into viewable, downloadable PNGs — directly in the browser.

Load textures

Supports the "GPU-dependent" container format (format 0x0C), which stores the same image three times — once each as DXT5, PVRTC-A, and ATC — for different mobile GPUs. This tool decodes RGBA8888, RGBA4444, ETC1, and DXT5/BC3 to real pixels; PVRTC and ATC blocks are extracted as raw bytes (their block-interpolation decode isn't implemented here) so you can still hand them to a dedicated tool.
