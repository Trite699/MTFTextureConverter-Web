MT Framework TEX ↔ PNG Converter

Header layouts, per-platform format tables and mip-offset handling are ported directly from Kuriimu2's plugin_mt_framework (MtTex.cs / MtTexSupport.cs). Every game platform (3DS/Vita, PS3, PS4, Switch, PC, Mobile) uses the same magic ("TEX ", or "\0XET" big-endian) but a different meaning for the same numeric format codes — so a platform is always identified first, then its own format table is used. GPU pixel un-swizzling is now implemented for 3DS/Vita (nested 8×8 Morton/Z-order tiling, ported from the community MT Framework 3DS texture notes) and PS3 (RSX's classic full-image Morton swizzle) and Switch (Tegra X1 block-linear GOB tiling, default 16-line GOB height) — these three now round-trip to clean, untiled images. PS4 (GNM tiling) is still not implemented — its tiling scheme isn't reliably documented in public tooling, so PS4 bytes are extracted from the correct file locations but may still render tiled/scrambled. PC and Mobile textures are stored linearly and are unaffected either way.

In-browser pixel shaders: RGBA8888, BGRA8888/ARGB8888, RGB888, BGR888, RGB565, RGBA5551, RGBA4444, L8, A8, L4, A4, LA88, LA44, RG88, ETC1, DXT1/BC1, DXT3/BC2, DXT5/BC3, plus the YCbCr and alpha-luminance color shaders MT Framework itself uses on some PS3/PS4/Switch/PC formats. BC7, ASTC, PVRTC, ATC, ATI1/ATI2 and ETC1A4 have no in-browser shader and are extracted as raw payloads for external tools (Kuriimu2, PVRTexTool, Noesis) — for 3DS/PS3/Switch these raw payloads are now de-tiled first, so they drop straight into those tools without an extra unswizzle pass.

Note: DXT1/BC1 and DXT3/BC2 and DXT5/BC3 block compression require width/height to be multiples of 4. For 3DS/Vita, PS3, and Switch targets the encoder now also re-tiles (swizzles) the pixel data to match real console GPU layout before writing, so these outputs should be usable directly in a console-swizzled archive, not just for PC-side inspection. PS4 output is still linear/untiled (GNM tiling not implemented), so it remains best used as a base for a proper swizzle pass in Kuriimu2.
